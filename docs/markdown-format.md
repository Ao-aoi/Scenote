# Scenote の Markdown 記法（形式バージョン 1）

Scenote は、シナリオを構造化データ（章 → 場面 → 要素）として保持し、Markdown と相互に変換する。
本書はその対応関係を定める。変換は `server/src/markdown.rs` がすべてプログラムで行う。

## 1. 要素

空行で区切られた 1 かたまり（ブロック）が 1 つの要素に対応する。要素の種類はブロックの先頭行で決まる。

| 種類 | 記法 | 例 |
|---|---|---|
| 地の文 `Narration` | マーカーなし | `夜の校舎は静かだった。` |
| 台詞 `Dialogue` | `**話者**: 本文` | `**アリス**: 「誰かいるの？」` |
| 台詞（話者なし） | `[台詞] 本文` | `[台詞] 「……」` |
| 動作 `CharacterAction` | `[動作] 本文` / `[動作:名前] 本文` | `[動作:アリス] 扉に手をかける。` |
| 演出 `Direction` | `[演出] 本文` | `[演出] SE: 扉のきしむ音` |
| 選択肢 `Choice` | `[選択肢] 本文` | `[選択肢] - 中に入る` |
| 遷移 `Transition` | `[遷移] 本文` | `[遷移] 結末へ` |
| 変数の変更 `VariableChange` | `[変数] 本文` | `[変数] 勇気を得る` |
| その他の種類 | `[type:種類名] 本文` / `[type:種類名:名前] 本文` | `[type:Memo] 後で直す` |

- 台詞のコロンは半角 `:`・全角 `：` のどちらでも読み込める（書き出しは半角）。
- 話者つきの地の文は `[地の文:名前] 本文` と書く。
- 本文は複数行にできる。2 行目以降はそのまま続けて書く。
- 上記のマーカーに当てはまらないブロックは、すべて地の文として**本文をそのまま**保持する。
  見出し（`###` 以下）、リスト、引用、表、コード、HTML などの Markdown 記法を削除・変換しない。
- 話者名に `[` `]` `:` `*` と改行は使えない。

### エスケープ

本文を失わずに往復変換するため、行頭の `\` を次のように使う。

| 本文の行 | Markdown での表記 |
|---|---|
| 空行（空白のみの行を含む） | `\`（空白のみの行は `\` + その空白） |
| マーカーや章・場面の見出しと紛らわしい行 | 行頭に `\` を付ける（例: `\[演出] という文字列`） |
| 上記の表記と同じ形にすでになっている行 | さらに `\` を 1 つ付ける |

これら以外の行頭の `\`（`\*強調ではない\*` など）は変更しない。

## 2. プロジェクト全体の文書

プロジェクトの書き出しは 1 つの Markdown ファイルになる。

- 先頭の front matter に形式バージョンとプロジェクト名を記録する。
- `# ` 見出しが章、`## ` 見出しが場面。見出しはブロックの先頭行にあるときだけ構造として解釈する。
- 見出しより前に本文がある場合は、「無題」の章・場面を補って読み込む。
- 場面単位の Markdown 編集（エディタの「Markdown」モード）では見出しを構造として解釈せず、地の文として扱う。

```markdown
---
scenote: 1
title: "月夜の館"
---

# 第1章

## 玄関

館の扉が、ひとりでに開いた。
\
冷たい空気が頬をなでる。

**執事**: ようこそ。お待ちしておりました。

[動作:アリス] 一歩、後ずさる。

[演出] BGM: 停止

[選択肢] - 中に入る
- 引き返す
```

## 3. Markdown で表現しない情報

要素の ID、リビジョン、作成・更新日時、編集の由来（`origin`）、拡張属性（`attrs`）は Markdown には含めない。
これらを含む完全な構造は JSON 書き出し（`format: "scenote-project"`、`schema_version` つき）で取得できる。

場面の Markdown を編集して保存した場合、内容が変わっていない要素は ID とリビジョンをそのまま保ち、
書き換えられた要素は位置の対応から「同じ要素の編集」として扱う。

## 4. 現時点の制限

- Markdown・JSON の**インポート**（ファイルからのプロジェクト作成）は未実装。解析処理（`parse_project`）は実装・テスト済み。
- 選択肢の移動先・条件式・変更式、遷移先などの分岐の設定は Markdown に含めない。JSON 書き出しとスナップショットには含まれ、場面の Markdown を編集しても既存の要素の設定は保たれる。
